# cmp-mechanoo

ComputerCraft (CC:Tweaked) programs for the CMP Minecraft server (1.21.1, NeoForge, Create + addons).
By Mechanoo.

> Work in progress. Nothing here is installable yet.

## Layout
- `lib/` shared libraries (UI, config, updater)
- `apps/<name>/` one folder per program
- `tests/` logic tests (run in CraftOS-PC with mocked peripherals)
- `install.lua` installer (planned)
